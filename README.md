# 黑玛项目管家 - H5 本地预览版

工地推进管理小程序 · 第一版（V1.0）本地可调试预览版本。

## 技术栈

- **Vue 3** + **Vite 5** - 现代化前端框架
- **Vant 4** - 移动端 UI 组件库（小程序风格）
- **Pinia** - 状态管理
- **Vue Router 4** - 路由
- **Sass** - 样式预处理

> 本套架构与未来微信小程序高度兼容，二期可一键迁移到 uni-app 或微信原生小程序。

## 快速开始

```bash
# 安装依赖（已完成）
npm install

# 启动开发服务器（默认端口 5173）
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

启动后访问： <http://localhost:5173>

> 💡 **手机预览**：用手机浏览器访问 `http://你电脑的局域网IP:5173`，可在真实手机上体验。

## 体验路径建议

1. **以"李辉煌（老板）"身份登录** → 看 **看板** 页（8 大卡片 + 超期项目 + 人员责任）。
2. 点击底部 **项目** → 浏览项目列表，按状态/超期筛选。
3. 进入 **橙堡精品酒店大堂照明** 项目详情 → 看 **14 状态节点的时间线**。
4. 点击任意节点 → 可上传资料、提交确认。
5. 底部 **问题** Tab → 体验问题闭环流程（待处理 → 处理中 → 待确认 → 闭环）。
6. 切换身份为 **罗爽（施工人员）** → 体验 **30 秒签到** 流程。
7. 切换身份为 **严静（新媒体）** → 体验素材库。

## 与正式版的差异

| 项目 | 本地预览版 | 上线版本（CloudBase） |
|---|---|---|
| 登录 | 选身份模拟 | 微信授权登录 |
| 数据 | 内存 mock | 云数据库 |
| 图片 | 本地预览 | 云存储 + CDN |
| 提醒 | 无 | 微信订阅消息 |
| 部署 | localhost | 微信小程序 + 后台云函数 |
